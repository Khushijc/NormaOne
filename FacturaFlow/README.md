# FacturaFlow: Facturas y Gastos (interactive prototype)

Mini-app 01 of the **Spain SME Compliance Portal** (BRD ES-SME-BRD-001 v1.0). This is a frontend-only, end-to-end prototype for:
- sales invoices
- rectifications
- simulated fiscal issue
- collections
- supplier invoices and employee expenses
- the accountant (gestoría) handover

It runs on fictitious demo data.

> **Not legal advice and not a certified billing system.** The fiscal provider, e-mail and document recognition are simulated. Nothing is sent to the AEAT.

## Run

```bash
cd frontend
npm install        # .npmrc sets legacy-peer-deps (works around an npm 10 peer-resolution bug)
npm run dev        # http://localhost:3001 (JornadaPulse uses 3002)
npm test           # Vitest: BRD acceptance scenarios against the service layer
npm run build      # type-check + production build
```

Use the **ES | EN** switch in the top bar to change the interface language; the choice is remembered in this browser. Spanish is the source language: records (audit trail, notifications), business data, the printed invoice and the CSV exports stay in Spanish, and system text is translated on screen through `src/i18n` (see `npx vitest run src/i18n` for coverage).

Requires Node 22.12 or later. Data persists in `localStorage`. Use **Configuración → Datos de demostración** to download a JSON copy, reset the demo data, or set a simulated working date.
